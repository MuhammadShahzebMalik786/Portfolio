# Portfolio Website - Antigravity Guidelines

Personal developer portfolio and project showcase website.

## Tech Stack & Architecture

- **Stack**: Semantic HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Components**:
  - `index.html`: Main landing page with responsive hero and showcase sections.
  - `styles.css` & `enhanced-styles.css`: Custom animations, dark/light styling, and layout.
  - `script.js`: Interactive navigation, scroll triggers, and project modals.
  - `chat-widget.js` & `chat-widget.css`: Embedded interactive AI assistant widget.
  - `projects/`, `about/`, `careers/`: Sub-pages and asset directories.

## Guidelines

1. **Performance**: Keep script loading asynchronous and optimize images.
2. **SEO & Accessibility**: Maintain valid schema markup in `index.html`, semantic tags, and valid meta descriptions.
